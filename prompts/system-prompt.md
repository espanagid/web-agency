# prompts/system-prompt.md — Промпт для старта нового чата

**Как использовать:** скопируй текст из блока ниже первым сообщением
в новый чат с AI-ассистентом. Приложи файлы `PROJECT.md` и `BUSINESS.md`
(а для технических задач — `TECH_STACK.md`). Это восстановит контекст
за 30 секунд.

---

## ТЕКСТ ПРОМПТА (копировать отсюда)

```
# Контекст проекта: Web Agency

Я разрабатываю агентство по созданию сайтов для малого бизнеса в Испании.
Основной продукт: продающие одностраничные лендинги с AI-ассистентом
и услуги по рекламе в Facebook/Instagram.

## Целевая аудитория
- Autónomos и pymes в Испании
- Начинающие предприниматели
- Русскоязычные экспаты с локальным бизнесом

## Ключевые файлы проекта (прикреплены)
- PROJECT.md — ядро проекта (цели, УТП, тарифы, правила)
- BUSINESS.md — unit-экономика и ценообразование
- TECH_STACK.md — стек, архитектура, схема БД
- ROADMAP.md — этапы разработки
- QUALITY_CHECKLIST.md — чек-лист качества
- AI_MODULE.md — архитектура AI-ассистента

## Основные тарифы
- Start: 490 € разово, 1-й год без абонплаты, со 2-го — 190 €/год
- Business: 990 € + 39 €/мес (или 390 €/год), с AI-ассистентом
- Реклама: настройка 300 € + ведение 199 €/мес
- Пакет Traffic Start: 449 € + 199 €/мес
- Пакет Full Funnel: 1 190 € + 39 €/мес + 199 €/мес

## Технический стек
- Next.js 15, TypeScript, Tailwind, shadcn/ui
- PostgreSQL + Prisma + pgvector
- Redis, MinIO, Caddy, Docker
- DeepSeek API (основной), OpenAI (fallback)
- WhatsApp Cloud API для уведомлений

## Архитектура
- maindomain.es — сайт агентства
- admin.maindomain.es — админка
- api.maindomain.es — AI API
- demo-{client}.maindomain.es — демо клиентов (временно)
- {client}.es — продакшн на домене клиента

## Правила работы со мной
1. Не предлагай WordPress — только Next.js
2. AI — только как отдельный SaaS-виджет, не встроенный в код сайта
3. Все решения учитывают рынок Испании (язык, законы, RGPD)
4. Только WhatsApp, никакого Telegram (в Испании это стандарт)
5. Качество важнее скорости — PageSpeed 95+, юридические страницы, accessibility
6. Только одностраничные лендинги на этапе 1 (многостраничники — этап 2)
7. Всё включено в тариф: домен, хостинг, SSL, юридические страницы, копирайтинг
8. Платишь после демо — сначала показываем результат, потом берём деньги
9. Никаких костылей — если что-то не влезает в шаблон, расширяем шаблон

## Что мне нужно сейчас
[ОПИШИ КОНКРЕТНУЮ ЗАДАЧУ]

## Формат ответа
- Конкретно, без воды
- Код — рабочий, готовый к копированию
- Если предлагаешь решение — обоснуй, почему именно оно
- Если видишь проблему в моей идее — скажи прямо
```

## Быстрые промпты для типовых задач

### Когда нужен новый файл документации

```
Создай файл [ИМЯ].md для проекта.

Содержание должно включать:
- [список разделов]

Стиль: как в PROJECT.md (структурировано, с таблицами,
без воды, готово к копированию в репозиторий).
```

### Когда нужен новый шаблон лендинга

```
Создай HTML-прототип лендинга для ниши [НИША].

Требования:
- Один HTML-файл, без внешних зависимостей (кроме шрифтов)
- Мобильная версия обязательна
- Структура: Hero, Услуги, Почему мы, Отзывы, FAQ, CTA, Footer
- AI-виджет как мок-ап в hero
- Юридические ссылки в футере (RGPD, Aviso legal, Cookies)
- Язык: испанский
- Палитра: подобрать под нишу
- Продающие тексты: бить в боль клиента
```

### Когда нужен код Next.js

```
Напиши компонент [ИМЯ] для Next.js 15 (App Router).

Требования:
- TypeScript, строгая типизация
- Tailwind CSS для стилей
- shadcn/ui если нужны готовые компоненты
- Server Component по умолчанию, Client — только если нужно
- Доступность (a11y): aria-атрибуты, keyboard navigation
- Не использовать any
```

### Когда нужна схема БД

```
Обнови схему Prisma в packages/db/prisma/schema.prisma.

Добавь модель [ИМЯ] с полями:
- [список полей]

Учти:
- Multi-tenant изоляция (tenantId на всех таблицах)
- Индексы для частых запросов
- Мягкое удаление (soft delete) если применимо
- Связи с существующими моделями
```

### Когда нужен промпт для AI-ассистента клиента

```
Создай system prompt для AI-ассистента ниши [НИША].

Контекст:
- Бизнес: [описание]
- Услуги: [список]
- Цены: [диапазон]
- Целевая аудитория: [описание]

Промпт должен:
- Определять роль и цель AI
- Задавать жёсткие правила (только RAG, не выдумывать)
- Описывать сценарий квалификации лида
- Задавать тон общения
- Включать плейсхолдеры для RAG-контекста
```

## Что делать, если AI потерял контекст

Если в середине чата ассистент «забыл», о чём вы говорили — скопируй:

```
Напомню контекст: [краткое описание 3–5 строк]
Продолжаем с того места: [последняя задача]
```

Если контекст потерян полностью — начни новый чат с полным
промптом выше.

## Пример правильно оформленного первого сообщения

```
# Контекст проекта: Web Agency
[скопирован весь промпт выше]

## Что мне нужно сейчас
Написать компонент Hero для шаблона dental в Next.js 15.
Компонент должен принимать пропсы: title, subtitle, ctaText,
ctaLink, imageUrl. Использовать Tailwind. Server Component.

## Формат ответа
Готовый файл `Hero.tsx` + короткое объяснение ключевых решений.
```

**Результат:** ассистент сразу в контексте, отвечает по делу,
не задаёт лишних вопросов, не предлагает WordPress.
