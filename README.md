# Web Agency

Агентство по разработке сайтов для малого бизнеса в Испании.
Продающие лендинги и сайты-визитки с интегрированным AI-ассистентом.

## Что внутри

- [`PROJECT.md`](./PROJECT.md) — ядро проекта: цели, УТП, тарифы, архитектура
- [`BUSINESS.md`](./BUSINESS.md) — экономика, конкуренты, ценообразование
- [`TECH_STACK.md`](./TECH_STACK.md) — стек, инфраструктура, схема БД
- [`ROADMAP.md`](./ROADMAP.md) — этапы разработки и текущий статус
- [`QUALITY_CHECKLIST.md`](./QUALITY_CHECKLIST.md) — чек-лист качества для каждого проекта
- [`AI_MODULE.md`](./AI_MODULE.md) — как работает AI-ассистент на сайтах клиентов
- [`docs/`](./docs/) — детальная документация
- [`templates/`](./templates/) — шаблоны сайтов по нишам
- [`prompts/`](./prompts/) — промпты для AI и для старта чатов с AI-ассистентом

## Быстрый старт

1. Прочитай `PROJECT.md` — там всё о продукте.
2. Смотри `ROADMAP.md` — что делаем сейчас.
3. Перед каждым новым проектом прогоняй `QUALITY_CHECKLIST.md`.
