# QUALITY_CHECKLIST.md — Чек-лист качества

Прогоняй этот чек-лист **перед каждым запуском** сайта клиента.
Если хотя бы один пункт красный — не сдаём работу.

---

## 1. Производительность

- [ ] **PageSpeed Insights ≥ 95** на мобильных
- [ ] **PageSpeed Insights ≥ 95** на десктопе
- [ ] **LCP < 2.5s** (Largest Contentful Paint)
- [ ] **CLS < 0.1** (Cumulative Layout Shift)
- [ ] **INP < 200ms** (Interaction to Next Paint)
- [ ] **TTFB < 600ms** (Time to First Byte)
- [ ] **Общий вес страницы < 1.5 MB**
- [ ] Изображения в WebP/AVIF
- [ ] Изображения lazy-load (кроме hero)
- [ ] Шрифты предзагружены (`font-display: swap`)
- [ ] Нет блокирующего JS
- [ ] CSS минифицирован
- [ ] Кэш браузера настроен

---

## 2. SEO

- [ ] `<title>` до 60 символов, с ключевым словом
- [ ] `<meta description>` до 155 символов
- [ ] Один `<h1>` на странице
- [ ] Иерархия заголовков корректна (h1 → h2 → h3)
- [ ] `lang="es"` (или соответствующий)
- [ ] Open Graph теги (og:title, og:image, og:description)
- [ ] Twitter Card теги
- [ ] `sitemap.xml` создан и доступен
- [ ] `robots.txt` корректный
- [ ] Canonical URL установлен
- [ ] Schema.org разметка (LocalBusiness + Service + FAQ)
- [ ] Favicon и apple-touch-icon
- [ ] HTTPS с редиректом с HTTP
- [ ] Нет битых ссылок
- [ ] Alt-тексты у всех изображений
- [ ] Внутренние ссылки описательные

---

## 3. Мобильная версия

- [ ] Открывается корректно на iPhone и Android
- [ ] Кнопки минимум 44×44 px
- [ ] Текст читается без зума
- [ ] Формы удобны на мобильных
- [ ] WhatsApp-кнопка доступна в один тап
- [ ] Телефон кликабелен (`tel:`)
- [ ] Email кликабелен (`mailto:`)
- [ ] Навигация работает
- [ ] Никакого горизонтального скролла

---

## 4. Контент

- [ ] Заголовок бьёт в боль клиента
- [ ] Нет орфографических ошибок (проверить через LanguageTool)
- [ ] Все цены актуальны
- [ ] Телефон, email, адрес верны
- [ ] Юридические страницы заполнены:
  - [ ] Aviso legal
  - [ ] Política de privacidad (RGPD)
  - [ ] Política de cookies
- [ ] Cookie consent работает
- [ ] Ссылки на соцсети клиента
- [ ] Карта Google Maps встроена (если применимо)
- [ ] Часы работы указаны

---

## 5. Формы и уведомления

- [ ] Форма заявки отправляется
- [ ] Валидация полей работает
- [ ] Email приходит на почту клиента
- [ ] WhatsApp-уведомление приходит
- [ ] Автоответ клиенту (если настроен)
- [ ] Заявка появляется в админке
- [ ] Защита от спама (honeypot или Turnstile)
- [ ] Понятный success-экран после отправки
- [ ] Понятный error-экран при ошибке

---

## 6. AI-ассистент (для Business-тарифа)

- [ ] Виджет загружается < 1 сек
- [ ] AI отвечает < 2 сек
- [ ] AI отвечает на языке посетителя
- [ ] AI не галлюцинирует (проверить 20 тестовых вопросов)
- [ ] База знаний загружена и работает
- [ ] Захват контактов работает
- [ ] Квалификация лидов работает (hot/warm/cold)
- [ ] Эскалация на WhatsApp работает
- [ ] Лимиты сообщений соблюдаются
- [ ] Диалоги сохраняются в БД
- [ ] Виджет адаптивен на мобильных
- [ ] Виджет закрывается и не блокирует контент

---

## 7. Безопасность

- [ ] SSL активен (A+ на SSL Labs)
- [ ] HTTP → HTTPS редирект
- [ ] HSTS заголовок
- [ ] CSP заголовок
- [ ] X-Frame-Options
- [ ] X-Content-Type-Options
- [ ] Referrer-Policy
- [ ] Permissions-Policy
- [ ] Формы защищены от CSRF
- [ ] Rate limiting на API
- [ ] Нет открытых API-ключей в клиентском коде
- [ ] Нет консольных ошибок
- [ ] Нет утечек данных в логах

---

## 8. Юридические требования (Испания)

- [ ] Aviso legal с данными компании (CIF/NIF, dirección)
- [ ] Política de privacidad согласно RGPD
- [ ] Política de cookies с детальным списком
- [ ] Cookie banner с опцией «Rechazar todas»
- [ ] Consentimiento до загрузки аналитики
- [ ] Ссылка на политику в футере
- [ ] Данные для контакта (email, телефон)
- [ ] Если e-commerce: Términos y condiciones

---

## 9. Технические проверки

- [ ] Нет ошибок в консоли браузера
- [ ] Нет 404 в Network tab
- [ ] Все ссылки работают (проверить через Screaming Frog)
- [ ] Кастомная 404 страница
- [ ] Кастомная 500 страница
- [ ] Проверено на Chrome, Firefox, Safari
- [ ] Проверено на iOS Safari и Android Chrome
- [ ] `robots.txt` не блокирует важное
- [ ] Аналитика загружается
- [ ] Цели в аналитике настроены (заявка, клик по WhatsApp)

---

## 10. Финальная проверка

- [ ] Все тексты заменены на клиентские (не «Lorem ipsum»)
- [ ] Все изображения клиента (не стоки без лицензии)
- [ ] Логотип клиента на месте
- [ ] Цвета соответствуют бренду
- [ ] Домен подключён
- [ ] SSL работает
- [ ] PageSpeed 95+ подтверждён
- [ ] Демо закрыто `noindex` (если ещё не публикуем)
- [ ] Клиент получил доступ к админке
- [ ] Клиент получил инструкцию (видео 5–10 мин)
- [ ] Заявка прошла полный тест end-to-end

---

## Красные флаги — НЕ сдавать работу, если:

- ❌ PageSpeed < 90 на мобильных
- ❌ Есть ошибки в консоли
- ❌ Не приходят заявки
- ❌ AI галлюцинирует
- ❌ Нет юридических страниц
- ❌ Нет cookie consent
- ❌ Форма не отправляется
- ❌ SSL не работает
- ❌ Мобильная версия сломана
- ❌ Открыты API-ключи в коде

---

## Как использовать

1. Скопируй чек-лист в отдельный файл (или в Notion/Trello).
2. Прогоняй его для каждого проекта **перед публикацией**.
3. Фиксируй время на проверку (цель: 30 минут).
4. Если пункт не проходит — исправляй до сдачи.
5. Через 3 месяца проверь, какие пункты чаще всего падают → улучшай шаблон.

## Бонус: автоматизация проверок

| Инструмент | Что проверяет |
|---|---|
| PageSpeed Insights API | Скорость |
| Lighthouse CI | Всё сразу, можно в GitHub Actions |
| W3C Validator | HTML |
| SSL Labs | SSL |
| Screaming Frog (free 500 URL) | Битые ссылки |
| LanguageTool | Орфография |
| axe DevTools | Доступность |

Настрой Lighthouse CI в GitHub Actions — он будет автоматически
прогонять проверки на каждый PR. Это ловит 80% проблем до продакшена.
